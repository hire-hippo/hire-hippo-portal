Sync Settings — Share This Tracker

This file works offline on its own by default. To let everyone who has this file see each other's changes, connect it to one shared online endpoint below (a small Google Sheet + Apps Script backend works well — see instructions). Everyone using the tracker should paste the same URL.

Setup instructions (one-time, for whoever owns the tracker)
  1. Create a blank Google Sheet (this will just hold the shared data, no need to add columns).
  2. Go to Extensions → Apps Script, delete any starter code, and paste the script below.
  3. Click Deploy → New deployment → Web app. Set "Execute as: Me" and "Who has access: Anyone with the link". Deploy.
  4. Copy the Web App URL it gives you and paste it into the field above — send that same URL to everyone else who should share this tracker.

Already deployed an earlier version? Paste this updated code in, then use Deploy → Manage deployments → ✏️ edit → Version: New version → Deploy (the URL stays the same, so no need to reconnect).
